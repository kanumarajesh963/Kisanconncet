# KisanConnect

A complete farming companion app — weather alerts, mandi price tracking, IoT motor control, crop doctor AI, marketplace, and more, built for Indian farmers.

## Tech Stack

- React 19 + Vite
- React Router
- Recharts (price trend graphs)
- Lucide React (icons)
- Poppins (font)

## Status

Frontend prototype with mock data. Screens built so far:

- Login (Phone + OTP)
- Home / Dashboard
- Motor Control (IoT)
- Mandi Price Tracker

Remaining modules (Weather, Farming Calendar, Crop Doctor AI, Marketplace, Community Forum, Govt Schemes, Equipment Rental, Loans & Insurance, Soil Health) are scaffolded as routes and in active development.

## Getting Started

```bash
npm install
npm run dev
```

Runs on [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```
